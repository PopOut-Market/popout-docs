# 사업 배경

이 페이지는 제품 결정의 배경을 짧게 설명합니다. 무엇을 만들었는지는
[제품](../product/overview.md), 어떻게 만들었는지는
[엔지니어링](../engineering/architecture.md)을 보세요.

## 왜 만드는가

호주에서 매년 60만 명 이상의 국제 유학생과 20만 명 규모의 워킹홀리데이 메이커가
들어옵니다. 이들은 입국·졸업·귀국 시점마다 가구와 생활용품을 빠르게 사고팔아야 합니다.
현지 로컬도 고물가 환경에서 중고거래를 활발히 씁니다. 모나쉬 대학 조사에 따르면
호주인의 약 75%가 지난 1년 내 중고거래 경험이 있습니다.

그런데 이 수요를 받아 주는 시장은 Facebook Marketplace가 사실상 독점하고 있고, 나머지는
국적별 커뮤니티(카카오톡, 위챗, 샤오홍슈)로 흩어져 있습니다. 어느 쪽도 만족스럽지
않아서, 사용자는 **대체재가 없어 억지로 쓰는** 상태에 머물러 있습니다.

## 무엇이 문제인가

| 문제 | 내용 |
| --- | --- |
| **안전·신뢰** | PayID 환불 사기, 가짜 배송 링크, 허위 매물이 만연. 계정 연차·응답률·이행률 같은 객관적 신뢰 지표가 없음 |
| **대화 피로** | 반복되는 흥정, 거래 의사 없는 문의, 낯선 사람과의 장황한 대화. 언어가 다르면 더 큼 |
| **거래 이행** | 노쇼와 무응답이 잦고, 이미 팔린 물건이 계속 노출됨 |
| **발견성** | 거리 필터가 부정확해 원거리 매물이 과다 노출되고, 원하는 걸 찾는 데 오래 걸림 |
| **품질·운영** | 광고성 게시물에 개인 매물이 묻히고, 운영사가 전략적으로 신경 쓰지 않아 대응이 느림 |
| **파편화** | 국적별 커뮤니티는 닫혀 있어 거래 밀도가 안 나오고, 시장 전체의 네트워크 효과가 약해짐 |

특히 **하이퍼로컬 대면 직거래 전용 플랫폼의 공백**이 뚜렷합니다.

## 제품이 내린 답

문제 하나하나가 제품의 구체적 결정으로 이어집니다.

| 문제 | 제품에서의 답 | 자세히 |
| --- | --- | --- |
| 사기 | 대면 직거래만 허용. 결제·에스크로 링크 차단 | [마켓플레이스](../product/marketplace.md#신뢰와-안전) |
| 신뢰 지표 부재 | 만족한 거래 상대 수를 공개, 프로필 레벨 | [커뮤니티와 리워드](../product/community-and-rewards.md#거래-후-후기) |
| 대화 피로 | 게시글·상대별로 분리된 채팅방, 앱이 쓰는 시스템 안내 | [마켓플레이스](../product/marketplace.md#채팅) |
| 발견성 | 거리와 최신성으로 점수를 매기는 동네 피드, 도시 전체 검색 | [마켓플레이스](../product/marketplace.md#둘러보기) |
| 언어 파편화 | 등록 시점에 8개 언어로 번역해 저장, 언어를 넘나드는 검색 | [아키텍처](../engineering/architecture.md#언어를-넘나드는-검색이-되는-이유) |
| 등록 피로 | 사진에서 AI가 제목·설명·카테고리를 채움 | [마켓플레이스](../product/marketplace.md#판매하기) |
| 대면 안전 | 잘 알려진 공공장소 목록에서 만남 장소 선택 | [마켓플레이스](../product/marketplace.md#만남-장소) |

## 시장

- 호주 중고·재판매 시장 약 **49억 AUD**.
- 중고 의류는 2023년 약 5.78억 AUD → 2032년 약 16억 AUD 전망(연평균 11.9%).
- 참고 모델은 한국의 당근마켓, 일본의 지모티. 특히 당근마켓의 캐나다 진출 전략
  — 대도시 집중 → 네트워크 효과 → 확장 — 을 따릅니다.

## 서비스 범위

시범 운영은 멜버른 시티(City of Melbourne) 9개 구역입니다 — CBD, Carlton, Docklands,
East/North/West Melbourne, Parkville, Southbank, South Wharf. 내부 밀도 기준을 넘기면
인접 지역(Carlton North, Brunswick, Richmond 등)으로 확장합니다.
