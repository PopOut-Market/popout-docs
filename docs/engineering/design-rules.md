# 디자인 규칙

화면을 만들 때 지켜야 하는 수치 규칙입니다. 값을 임의로 고르지 않는 것이 이 문서의
전부입니다. 간격도, 글자 크기도, 모서리 반경도 정해진 목록에서만 고릅니다.

색상 토큰과 화면 유형은 [컨벤션](./conventions.md#디자인-토큰)에 있습니다. 여기서는
치수와 배치를 다룹니다.

## 간격 — 8pt 그리드

**8pt를 기본으로 쓰고, 4pt는 정렬이 8pt만으로 해결되지 않을 때만 보조로 씁니다.**

| 적용 범위 | 값 |
| --- | --- |
| 섹션 간격 | 24 또는 32 |
| 피드 그리드의 카드 간격 | **8** |
| 묶인 요소 사이 (라벨+입력, 제목+부제) | 12~16 |
| 아이콘과 글자 사이 | 8 |
| 카드 내부 패딩 | 12~16 |
| 모달 내부 패딩 | 24 |

**8 / 12 / 16 / 24 / 32 외의 값을 새로 만들지 마세요.** 분명한 이유가 있을 때만
예외입니다.

원칙은 하나입니다. **가까울수록 관계가 깊다** — 간격이 정보 구조를 표현합니다.

## 타이포그래피

시스템 폰트만 씁니다. iOS는 San Francisco, Android는 Roboto입니다. **커스텀 폰트를
추가하지 마세요.**

| 용도 | 크기 | 굵기 |
| --- | --- | --- |
| 화면 제목 | 20~24 | Bold (700) |
| 섹션 제목 · 가격 · 중요 라벨 | 16~18 | Medium~Bold (500~600) |
| 본문 · 카드 제목 · 버튼 | 14~16 | Regular (400) |
| 부가 정보 (위치, 날짜, 작은 라벨) | 12~13 | Regular, 회색 |

다섯 단계로 요약하면 **12 · 14 · 16 · 20 · 24** 입니다. 이 목록에 없는 크기를 쓰지
말고, 가장 가까운 값으로 맞추세요.

- 정보의 중요도는 **크기 + 굵기 + 대비**로 전달합니다.
- 제목은 언제나 본문보다 2~4pt 큽니다.
- 텍스트는 기본적으로 왼쪽 정렬입니다. 훑어 읽기 좋기 때문입니다.

## 아이콘과 터치 타깃

| 영역 | 아이콘 크기 |
| --- | --- |
| 탭바 · 헤더 | 24 |
| 작은 버튼 · 칩 내부 | 16~20 (글자 높이의 1.2~1.4배) |

:::warning[터치 영역은 44×44 아래로 내려가지 않습니다]

아이콘이 24라도 **누를 수 있는 영역은 최소 44×44**여야 합니다. 보이지 않는 패딩으로
확보하세요. 작은 화면에서도 줄이지 않습니다.

:::

## 구조 요소

| 요소 | 규격 |
| --- | --- |
| 헤더 높이 | 56~64 (세이프 에어리어 포함) |
| 탭바 높이 | 56 |
| 기본 버튼 높이 | 최소 44, 좌우 패딩 16, 반경 16~20 |
| 칩 높이 | 32~36, 패딩 6(세로)×12(가로), 반경 16~20 |

모서리 반경은 **12 / 16 / 20** 세 가지만 씁니다. 카드와 이미지는 12입니다.

## 피드 카드

메인 판매 피드는 2열 그리드입니다.

```
cardWidth = (screenWidth - (8 * 3)) / 2
```

왼쪽 여백 8, 가운데 간격 8, 오른쪽 여백 8을 전제한 식입니다.

| 요소 | 규칙 |
| --- | --- |
| 썸네일 | 1:1 정사각형, 가운데 기준 크롭 |
| 카드 높이 | 썸네일 높이 + 제목·가격 영역 48~64 |
| 제목 | 최대 2줄 |
| 가격 | Bold, 대비 높게 |
| 반경 | 카드와 이미지 모두 12 |

카드 간격이 좁으면 피드가 답답해 보입니다. 8을 지키세요.

## 반응형

너비에 따라 배치가 적응해야 합니다. **글자 크기와 터치 영역은 화면 크기에 따라 변하지
않습니다.** 비율 기반 너비는 그리드와 컨테이너에만 적용합니다.

| 구간 | 너비 | 규칙 |
| --- | --- | --- |
| 좁은 화면 | 360pt 미만 | 2열 유지, 긴 제목은 말줄임 처리 |
| 표준 | 360~420pt | 기본 레이아웃, 위 카드 너비 공식 적용 |
| 큰 화면 | 420pt 초과 | 2열 유지하되 카드 너비를 비례 확대 (3열로 늘리지 않음) |
| 태블릿 | 600pt 이상 | **4열** |

좌우 안전 여백은 `min(16, screenWidth * 0.05)`입니다. 콘텐츠가 화면 끝에 붙지 않게
합니다.

:::note[앱은 현재 휴대폰 전용입니다]

태블릿 구간은 규칙으로만 정의되어 있고, 실제 앱은 iPhone 전용에 Android 태블릿도
제외되어 있습니다. [아키텍처](./architecture.md#배포-범위)를 보세요.

:::

## 그림자

| Elevation | 쓰임 | Blur |
| --- | --- | --- |
| 1~2 | 카드 | 4~6 |
| 3~4 | 떠 있는 요소 | 8 |
| 6+ | FAB · 모달 | 12~24 |

**꼭 필요한 곳에만 적게** 씁니다. 과하면 촌스럽고 성능에도 좋지 않습니다. 겹치는 강한
그림자는 피하세요.

## 상호작용

- 탭하면 **100ms 안에** 시각적 반응이 있어야 합니다 (투명도 변화나 리플).
- 플랫폼에 맞는 곳에서는 스와이프 백을 지원합니다.
- 피드와 목록은 로딩 중 스켈레톤을 보여 줍니다. 자세한 규칙은
  [컨벤션](./conventions.md#ui-상태)에 있습니다.
- 무거운 애니메이션을 넣지 마세요. 움직임은 은은하고 가볍게 유지합니다.

## 대비

WCAG 기준으로 **최소 4.5:1**을 지킵니다. 브랜드 강조색과 경고색은 분명히 구분되어야
하고, 회색은 4~6단계 계층을 갖춥니다.

## 하지 말 것

- 정해진 범위 밖의 간격·글자 크기·반경을 새로 만들기
- 커스텀 폰트 추가
- 터치 영역을 44×44 아래로 줄이기
- 명시적 요구 없이 메인 피드를 2열에서 바꾸기
